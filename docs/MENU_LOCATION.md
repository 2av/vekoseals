# Menu Location Guide

## Desktop View (> 768px width)

The menu is located on the **LEFT SIDE** of the page:
- Fixed sidebar, always visible
- 250px wide
- Contains navigation links: HOME, ABOUT, CAPABILITIES, PRODUCTS, INQUIRY, CONTACT US
- Active page is highlighted in orange

## Mobile View (≤ 768px width)

The menu is **HIDDEN by default** and opens when you click the menu icon:

1. **Menu Icon Location:**
   - Orange button in the logo bar (top-left area)
   - Click this to open the sidebar menu

2. **When Menu Opens:**
   - Sidebar slides in from the left
   - Dark overlay appears behind it
   - Menu items are visible inside the white sidebar
   - Close button (X) appears in top-right of sidebar

3. **To Close Menu:**
   - Click the X button in the sidebar
   - Click outside the sidebar (on the dark overlay)
   - Click any menu link

## Troubleshooting

If menu is not visible:

1. **Desktop:** Check if sidebar is on the left side of the page
2. **Mobile:** 
   - Click the orange menu button in the logo bar
   - Sidebar should slide in from left
   - If white box appears but no menu items:
     - Clear browser cache
     - Check browser console for errors
     - Try hard refresh (Ctrl+F5)
